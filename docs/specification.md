# 現行仕様

2026-11-15時点の実装です。構成は[構成](architecture.md)、保存構造は[DB](database.md)、導入手順は[README](../README.md)を参照してください。

## 対象と権限

1工場の切削工具を管理します。ロールは作業者（WORKER）と管理者（ADMIN）の2種類です。

| 操作 | 作業者 | 管理者 |
| --- | --- | --- |
| 工具一覧・詳細、全員の過去履歴・単価の参照 | 可 | 可 |
| 工具の新規登録、入庫・出庫 | 可 | 可 |
| 発注の確認：発注済みへ登録・一覧の取消 | 可 | 可 |
| 自分のパスワード変更 | 可 | 可 |
| 工具情報・在庫・発注数・発注ラインの編集 | 不可 | 可 |
| 入出庫履歴の取消、発注済みの未入庫分の取消API | 不可 | 可 |
| Excel一括登録・変更・一覧出力 | 不可 | 可 |
| ユーザー登録・編集・ロール変更・無効化 | 不可 | 可 |
| 初期在庫登録API | 不可 | 可 |

匿名アクセスは画面ではログインへ誘導し、APIでは401です。権限不足はAPIで403です。画面の非表示に加えてサービス内でも認可します。

## 画面

| URL | 内容 |
| --- | --- |
| `/login` | 社員IDとパスワードによるログイン |
| `/dashboard` | マイページ、工具検索、工具一覧、メニュー |
| `/tools/new` | 工具登録 |
| `/tools/[id]` | 入庫・出庫、工具情報、変更履歴3件、直近の入出庫5件 |
| `/tools/[id]/edit` | 管理者の工具情報変更 |
| `/history` | 全員の入出庫履歴、検索、管理者の取消 |
| `/orders` | 発注リストと発注の確認 |
| `/tools/import` | 管理者のExcel一括登録・変更 |
| `/account/password` | 本人のパスワード変更 |
| `/admin/users` | 管理者のユーザー管理 |

`/tools` は検索条件を維持してマイページへ転送します。共通の上段にToolStock Manager、右側にログイン情報とログアウトを置きます。メニューはマイページのみ、ほかの業務画面にはマイページへ戻るリンクを表示します。発注リストが残っていれば、メニューボタンと発注リストリンクに黄色の「要確認 ○件」を表示します。表示件数はページ表示時に取得します。

工具詳細には発注対象の選択欄、発注済み・未入庫の独立セクションを表示しません。変更履歴の操作者欄は氏名のみです。ユーザー一覧は社員IDの部分一致検索、20件ごとのページ切り替え、行を開いての編集に対応します。

## 工具と数量

工具の入力は品目コード・品目名・カテゴリー・在庫・発注ライン・発注数・発注単価・入数・部門・棚番です。編集では状態も変更できます。発注済みは自動集計です。発注単位・在庫単位の名前は保存・表示しません。

| 項目 | 制約 |
| --- | --- |
| 品目コード | 半角英数字・ハイフン・アンダースコア32文字以内、英大文字へ正規化、重複不可、登録後変更不可 |
| 品目名 | 必須、100文字以内 |
| カテゴリー | ドリル・エンドミル・タップ・リーマ・チップ。保存コードはDRILL・END_MILL・TAP・REAMER・INSERT |
| 在庫・発注ライン・発注数 | 0～2,147,483,647の整数 |
| 入数 | 1～2,147,483,647の整数、初期値1 |
| 発注単価 | 0以上、整数部12桁・小数部2桁以内 |
| 部門 | 未設定、17314、17361、17362、17363 |
| 棚番 | 任意、100文字以内。既存の長い値を未変更で保持可能 |

入数は登録・編集とExcelで設定する計算用の値です。工具一覧・詳細・履歴・発注リストには注記を表示しません。

一覧は「品目コード・品目名・カテゴリー・在庫・発注済み・発注ライン・発注数・発注単価・部門・棚番」です。品目コード・品目名は詳細へのリンクです。品目コードと品目名の部分一致、カテゴリーで絞り込み、50件ごとに表示します。通常は有効な工具が対象です。在庫0と不足状態を色で区別し、不足判定は在庫と発注済みの合計が発注ラインを下回る場合です。

## 在庫と履歴

入庫は在庫を増やし、出庫は在庫を減らします。数量は1以上の整数です。画面は確定後の在庫見込みを表示します。理由や設備の指定は不要です。内部の棚ID・残高・履歴を維持し、表示用の棚番変更で在庫を移動しません。

通常入庫は工具の古い発注から未入庫数を減らします。複数発注にまたがる入庫に対応し、発注残を超えた入庫分は通常の在庫追加です。消込の内訳を監査に保存し、取消時に復元します。工具情報の在庫修正は発注消込を行いません。

管理者の取消は元の履歴を変更せず逆取引を追加します。二重取消、出庫可能在庫不足、数量上限超過は拒否します。同じリクエストキーの成功済み操作を再送しても二重反映しません。取消では当時の単価・金額を戻します。

履歴列は「日時・品目コード・品目名・カテゴリー・入出庫履歴・数量・操作者・在庫数・単価・金額」です。在庫数は取引直後の値です。日時は日本時間、取消は在庫増・在庫減の方向を区別します。品目コード・カテゴリー・入出庫・操作者・日付範囲・単価範囲で検索し、50件ごとに表示します。新規ユーザーも登録前の履歴を参照できます。

## 発注

出庫後に次の条件を満たすと、工具ごとに1行を発注リストへ登録・更新します。

```text
在庫 + 発注済み（未入庫数） < 発注ライン
```

等しい場合は掲載しません。入庫・履歴の取消・在庫の手修正だけでは新規掲載しません。日時と操作者は最新の条件該当出庫です。

発注リストは「日時・品目コード・品目名・カテゴリー・発注数・操作者・発注単価・部門・発注の確認」です。作業者と管理者が「発注済みへ登録」「取消」を操作できます。数量は工具に設定された発注数を使い、確認欄に数量入力は置きません。

- 発注済みへ登録：発注数×入数を発注済みへ加算し、発注リスト行を削除します。発注時点の数量・入数・発注単価を固定保存します。
- 一覧の取消：発注せずリスト行だけを削除します。工具の発注数設定は維持します。
- 発注済み：各発注の数量×入数から入庫済み・取消済みを引いた合計です。工具マスタの入数変更で過去発注を再計算しません。

外部の仕入先への注文送信は行いません。旧仕入先・旧発注書・旧明細テーブルは整理移行で退避・削除し、未入庫分だけ現行の発注記録へ引き継ぎます。

## 金額

発注単価は工具に登録した価格です。入出庫時の単価・金額は次で固定保存します。

```text
履歴単価 = 発注単価 ÷ 入数
符号付き金額 = 発注単価 × 符号付き数量 ÷ 入数
```

計算はDecimalで行います。履歴単価は小数8桁、金額は小数2桁まで保存します。工具・発注リスト・Excelの発注単価は整数表示ですが、小数の保存値を丸め直しません。履歴の単価・金額は表示上小数2桁まで、金額は絶対値です。0円と未設定を区別します。旧履歴は保存済み単価から計算したLEGACY、新処理はMASTERとして計算根拠を保持します。

## 認証・ユーザー

社員IDとパスワードを使用し、パスワードは8～128文字です。scryptのハッシュを保存し、セッションの生トークンはDBに保存しません。CookieはHttpOnly・SameSite=Lax、HTTPS時はSecureです。無操作30分または最長8時間で失効します。

ログイン失敗と本人パスワード変更の誤入力は、それぞれ15分間で5回を制限します。本人変更は現在のパスワードと新しいパスワードの確認入力が必要です。変更後は本人の全セッションを失効させます。管理者によるロール・有効状態・パスワードの変更でも対象者のセッションを失効させます。

最後の有効管理者を失う変更を拒否します。削除済みユーザーは通常の一覧・変更・認証から除外し、過去の履歴・監査の参照は保持します。画面では物理削除を提供しません。

## 提供しない機能

設備・仕入先・購買条件の管理画面、承認ワークフロー、旧発注書、棚卸画面、直接テーブルを編集するデータ管理、外部送信、月次集計画面は提供しません。
