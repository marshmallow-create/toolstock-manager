# Excel工具一括登録

管理者が `/tools/import` でテンプレートを取得し、内容を確認して新規工具をまとめて登録します。既存工具の更新には使用できません。通常の1件登録は両ロールに許可し、一括登録は `tools:import` 権限で管理者に制限します。

## 入力と確認

- `.xlsx` のみ、2MiB以下、空行を除いて200件まで。
- 列は品目コード・品目名・カテゴリー・在庫・発注ライン・発注数・単価・部門・棚番の9列。テンプレートに日本語見出しと候補・説明を含めます。
- 品目コード・品目名・カテゴリー・単価は必須。数量の空欄は0、部門・棚番は未設定可。値の制限は[通常登録](specification.md)と共通です。
- 既存コード、ファイル内の正規化後重複、数式、結合、想定外の列構成は行番号付きエラーにします。
- 確認画面に全件とエラーを表示します。確認時はDBに書き込まず、全件正常な場合のみ確定できます。

## 保存と保護

ページ・テンプレート・確認・確定APIと保存トランザクションで認可します。確認後に権限やDBの内容が変わった場合にも、確定時の再解析・認可・重複検証を適用します。

工具、内部在庫参照先、初期在庫、必要な取引・発注候補・監査を全件1トランザクションで保存します。途中失敗は全件ロールバックし、再送の二重登録は品目コードの一意制約で防ぎます。ファイルは確認中にブラウザが保持し、サーバーのファイル領域やDBへ保存しません。

通常の8KiB入力制限とは別にmultipartを受け付け、全体を2MiB+64KiB、展開後を8MiBに制限します。ZIPエントリー数、XMLの行・セル・シートIDも検査します。名前付き範囲、外部参照、マクロ、DOCTYPE、非標準のZIPパス等を拒否し、任意のExcelブック全般は取り込みません。

## 実装と検証

| 場所 | 責務 |
| --- | --- |
| `src/lib/masters/tool-import.ts` | 行検証、重複検出、一括保存 |
| `src/lib/masters/tool-workbook.ts` | ExcelJSによる生成・解析、yauzlとsaxesによる事前検査 |
| `src/lib/masters/import-request.ts` | multipart受付とサイズ制限 |
| `src/components/tool-import-form.tsx` | ファイル選択、確認表、確定 |
| `src/app/api/tools/import/` | 確認・確定とテンプレートAPI |

`npm.cmd run test:tool-import` は解析・保存を、ビルド後の `npm.cmd run test:tool-import-http` は認可・Origin・競合・確認と確定を検証します。両方とも全体テストに含まれます。現在の実行結果は[保守](maintenance.md)に記録します。
