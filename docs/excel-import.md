# Excel工具一括登録（2026-11-09）

利用者が承認した「テンプレート→アップロード・確認→エラー修正→新規一括登録」を実装する。既存コードの更新は行わない。

## 仕様

- 作業者・管理者のtools:create権限で利用。工具登録画面から `/tools/import` へ進む。
- `.xlsx` のみ、2MiB以下、データ200行まで。列は品目コード・品目名・カテゴリー・在庫・発注ライン・発注数・単価・部門・棚番。
- テンプレートは日本語見出し、分類と部門の候補、入力説明を含む。発注済みは自動集計なので取込しない。
- カテゴリー・部門・数量・単価の制限は通常登録と共通。空の在庫・発注ライン・発注数は0、単価は必須、部門・棚番は任意。
- 空行を除外。数式・結合・想定外の列構成を拒否。既存コードとファイル内重複は行番号付きエラー。
- 確認時はDBへ書かない。確認画面には取込対象全件とエラーを表示し、全件正常な場合のみ確定可能。
- 確定時もファイルを再解析・認可・検証し、現在のDBとの重複を確認。全件を1トランザクションで登録し、失敗は全件ロールバック。
- 通常登録と同じ工具・初期在庫・履歴・発注候補・監査を作成。再送による二重登録はコードの一意性で防ぐ。
- ファイルはブラウザが確認中に保持し、サーバーのファイル領域やDBへ保存しない。送信元・サイズ・展開サイズを検査する。
