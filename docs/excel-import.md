# Excel一括登録・変更

管理者が `/tools/import` から操作します。通常の工具登録は両ロールに許可しますが、Excel一括処理と出力は管理者専用です。関連仕様は[仕様](specification.md)を参照してください。

## 共通テンプレート

操作切り替えの外に、登録・変更共通のダウンロードボタンを1つ表示します。`GET /api/tools/import/template` は `toolstock-template.xlsx` を返します。シート名は「工具登録・変更」、説明は「入力方法」シートにあります。旧modeパラメーターを指定しても共通テンプレートを返します。

入力列は次の10列です。2行目から入力します。

| 列 | 項目 | 登録時 | 変更時 |
| --- | --- | --- | --- |
| A | 品目コード | 必須・未登録コード | 必須・既存コード |
| B | 品目名 | 必須 | 空欄は保持 |
| C | カテゴリー | 5候補から必須 | 空欄は保持 |
| D | 在庫 | 空欄は0 | 空欄は保持、0は0へ変更 |
| E | 発注ライン | 空欄は0 | 空欄は保持 |
| F | 発注数 | 空欄は0 | 空欄は保持 |
| G | 発注単価 | 必須 | 空欄は保持、0は0円へ変更 |
| H | 部門 | 空欄可・4候補 | 空欄は保持 |
| I | 棚番 | 空欄可 | 空欄は保持 |
| J | 入数 | 空欄は1、1以上の整数 | 空欄は保持 |

部門・棚番を空欄へ変更する操作はExcelでは提供しません。発注単価は整数表示ですが、小数部2桁以内の入力値を保持します。先頭0を含むコードは文字列で入力します。

旧「工具登録」は登録時、旧「工具変更」は変更時に読み込めます。旧9列・12列、旧「単価」見出しも受け付けます。旧12列の在庫単位・発注単位は無視し、L列の入数を読み込みます。旧9列の登録は入数1、変更は入数を保持します。

## 確認・確定

ファイルは.xlsxのみ、2MiB以下、空行を除いて200件までです。画面で「新規登録」または「一括変更」を選び、ファイル選択後に内容を確認します。操作切り替えやファイル変更時は、前の確認内容を破棄します。

確認ではDBを変更せず、実際の行番号・入力値・エラーを表示します。変更の場合は変更前→変更後と変更件数を表示します。重複コード、候補外のカテゴリー・部門、不正な数量・価格、必須不足は確定できません。

確定時も認証・権限と内容を再検証します。変更はpreviewTokenで工具・残高・発注ライン・発注数とファイル内容を照合し、確認後の変更は409で再確認を求めます。全行を1トランザクションで保存し、途中失敗や1件でもエラーがあれば全件を戻します。新規登録の再送は既存コードの重複として拒否します。

`POST /api/tools/import` はmultipartでfile・mode（create/update）・action（preview/commit）を受け取ります。変更確定にはpreviewTokenが必要です。Originとサーバー側権限を確認します。

## 一覧出力

管理者はマイページの「Excelダウンロード」から、検索条件に一致する全工具を出力できます。画面のページ番号には限定されません。通常の対象は有効工具です。

出力は一括変更に使える「工具変更」シートの10列で、現在値を含みます。200件以内は.xlsx、201件以上は200件ごとの.xlsxをZIPにまとめます。該当なしは説明付きの空テンプレートです。未編集の出力を読み込んでも変更を発生させません。旧日本語カテゴリーや既存の長い棚番も未変更なら保持します。

## ファイル検査

解析前にZIP内の実展開量とXMLを検査します。数式・特殊セル・結合・マクロ・暗号化・外部参照・名前付き範囲・想定外の列、過大な行番号・列番号・シート構成を拒否します。解析・保存はサーバーで行い、Excel用ライブラリーをブラウザへ配布しません。

関連テストは `npm.cmd run test:tool-import` と、ビルド後の `npm.cmd run test:tool-import-http` です。両方とも全体テストに含みます。
