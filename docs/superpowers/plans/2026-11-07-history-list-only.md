# 入出庫履歴を一覧に集約

指示: 入出庫履歴の詳細ページは不要。

- 詳細ページと一覧からの詳細リンクを削除する。工具へのリンクは維持する。
- 入出庫・取消のHTML送信後は対象工具で絞った履歴一覧へ戻し、成功メッセージを表示する。
- 管理者の理由付き取消は履歴一覧の該当行内へ移す。取消済み取引・逆取引・作業者には操作を出さない。
- JSON APIの取引詳細、認証・権限・同一キー再送・数量整合性・過去のデータは維持する。
- テスト、ビルド、実ブラウザで詳細ページ廃止と一覧・戻るリンクを検証する。

検証済み: npm.cmd test（本番ビルドを含む）成功。実際の3000番ポートをChromiumの1440px/768pxで確認し、旧詳細URLの404、詳細リンクの削除、履歴一覧・戻るリンクを確認。HTTPテストで入出庫・取消後の一覧遷移、管理者の一覧内取消、作業者には取消を出さないことを検証。独立レビューで指摘なし。
