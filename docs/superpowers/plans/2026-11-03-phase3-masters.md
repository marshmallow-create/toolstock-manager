# Phase 3 — 工具・保管場所マスタの計画

現行仕様は2026-11-07の簡素化を反映する。元のPhase 3実装と当時の検証は完了済み。今回の変更進捗と検証は2026-11-07-simple-inventory.mdで管理する。

**Goal:** 工具検索、工具・保管場所管理、棚別在庫、再送に強い初期在庫登録を提供する。

## 現行契約

- 作業者と管理者が検索・棚別在庫を参照する。工具・保管場所・単価・初期在庫は管理者が管理する。
- 設備・仕入先・購買条件の操作を廃止し、旧APIは404。既存DB行・参照を保存する。
- MastersServiceはlistTools/toolDetail/listMasters/createTool/updateTool/createMaster/updateMaster/registerInitialStock。kindはlocationsだけ。saveSupplierItemは提供しない。
- 工具単価はtools.unit_priceを優先し、NULLの旧工具だけ旧優先条件の価格で補う。作業者へ単価を、どの公開DTOへも仕入先情報を含めない。
- 初期在庫は工具×棚に一度だけ。0も登録済み。正数RECEIVEと監査を原子的に保存し、0の再送も監査で判定する。
- コード正規化、一意制約、単位変更制限、閾値、整数数量、Decimal金額、UTC保存、追記型履歴を維持する。

## 実装順序

1. 廃止API404と保管場所の管理、単価優先順、非公開DTOの回帰期待をテストへ追加する。
2. マスタサービスとDTOを保管場所・工具へ整理する。
3. 画面・APIから設備/仕入先/購買条件の操作を削除する。
4. 初期在庫と工具登録の競合・再送・原子性が維持されることを検証する。
5. 関連Markdownを現行仕様へ更新し、型検査・ビルド・専用DB/HTTP・ブラウザで確認する。

担当分担は2026-11-07-simple-inventory.mdに従う。既存変更・履歴を保持し、自動コミット・本番・実データ・外部送信は行わない。
